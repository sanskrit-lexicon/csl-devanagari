## Project Overview

**csl-devanagari** is a Sanskrit Lexicon **converter** repository — part of the Cologne Digital Sanskrit Lexicon (CDSL) infrastructure. Purpose: a Devanagari mirror of every [csl-orig](https://github.com/sanskrit-lexicon/csl-orig) SLP1 source so a proofreader can check a correction in native script.

## How to run

Needs [indic-transliteration](https://pypi.org/project/indic-transliteration/) and a sibling [csl-orig](https://github.com/sanskrit-lexicon/csl-orig) clone (the round-trip `diff` step reads `../../csl-orig/v02/<dict>/<dict>.txt`).

One dictionary:

```bash
cd scripts
bash redo.sh mw
```

All dictionaries:

```bash
cd scripts
bash redo_all.sh
```

Converter unit tests (from repo root):

```bash
python -m unittest discover -s scripts -p "test*.py"
python -m py_compile scripts/to_devanagari.py scripts/to_slp1.py
```

Direct converter (same as `redo.sh` first step): `python3 scripts/to_devanagari.py mw`. Reverse: `python3 scripts/to_slp1.py mw`.

## What not to touch

- Do **not** hand-edit `v02/<dict>/<dict>.txt` — those files are generated by `scripts/to_devanagari.py` from csl-orig SLP1. Regenerate via `redo.sh`, then review `diff/<dict>.txt`.
- `slp1/` is an untracked intermediate for the round-trip; do not commit it.
- Do **not** commit or PR into [csl-orig](https://github.com/sanskrit-lexicon/csl-orig) from here. Source corrections go through the queued monthly batch-PR path.
